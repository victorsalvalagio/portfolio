#  Portfólio Pessoal

Portfólio pessoal desenvolvido para apresentar meus projetos, conhecimentos e experiências na área de tecnologia.

##  Sobre o projeto

Este projeto foi desenvolvido utilizando **HTML, CSS e JavaScript**, com foco em criar uma página pessoal responsiva, organizada e com uma interface moderna.

##  Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Material Symbols

##  Seções

*  Início
*  Sobre mim
*  Habilidades
*  Projetos
*  Contato

##  Objetivo

Utilizar o projeto como meu portfólio pessoal e também como forma de demonstrar minha evolução nos estudos e projetos relacionados à tecnologia.
